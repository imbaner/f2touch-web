# F2 Touch — web beta

[Play at play.f2touch.com](https://play.f2touch.com) · [Android releases](https://github.com/imbaner/fallout2-ce-mobile/releases/latest) · [Report a problem](https://github.com/imbaner/fallout2-ce-mobile/issues)

Fallout 2 with every screen rebuilt for fingers. Touch adaptation by imbaner, built on [Fallout 2: Community Engine](https://github.com/fallout2-ce/fallout2-ce).

## Install on iPhone or iPad

1. Open [play.f2touch.com](https://play.f2touch.com) in Safari, choose **Share → Add to Home Screen**, then open the new icon. Do this before importing: the installed app and a browser tab can have separate storage.
2. Prepare your own Fallout 2 installation on a computer (GOG, Steam or Epic Games). Install any mods there following their authors' instructions, then transfer a ZIP of the prepared game to Files on your device.
3. Choose that ZIP in F2 Touch, review the detected game and import it. Start the game in landscape. PC saves can come along with your game.

After the app has opened online and finished preparing its offline files, it can start without an internet connection. New app builds download online and apply outside an active game. Game resources, saves and settings are stored separately from the app cache. Keep using the same address and export save backups from **Settings → Game files**; clearing website data removes locally stored progress.

Early mod support: Fallout Et Tu (Fallout 1), Sonora, Nevada and Resurrection. Compatibility and complete playthroughs are not guaranteed. This is a beta; the latest build still needs a final physical-iPhone check for touch, keyboard, background audio and offline restart. Simulator checks do not cover all device behavior.

## Установка на iPhone и iPad

1. Откройте [play.f2touch.com](https://play.f2touch.com) в Safari → **Поделиться → На экран «Домой»**, затем запустите новый значок. Сделайте это до импорта: у приложения и вкладки Safari может быть разное хранилище.
2. Подготовьте свою копию Fallout 2 на компьютере (GOG, Steam или Epic Games), при необходимости установите моды по инструкциям их авторов. Перенесите ZIP подготовленной игры в «Файлы» на устройстве.
3. Выберите ZIP в F2 Touch, проверьте найденную игру и подтвердите импорт. Играйте в альбомной ориентации. Сохранения с ПК можно перенести вместе с игрой.

После первого запуска онлайн и подготовки офлайн-файлов приложение работает без интернета. Обновления приложения применяются вне запущенной игры; ресурсы, сохранения и настройки хранятся отдельно. Делайте резервные копии через **Настройки → Файлы игры**: очистка данных сайта удаляет локальный прогресс.

Поддержка Et Tu, Sonora, Nevada и Resurrection ранняя, прохождение без ошибок не гарантируется. Это бета: последняя сборка ещё требует финальной проверки на настоящем iPhone — касания, клавиатура, звук после фона и холодный офлайн-запуск.
