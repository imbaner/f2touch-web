# F2 Touch — web app

The site behind [play.f2touch.com](https://play.f2touch.com): the browser build of [Fallout 2 CE Mobile](https://github.com/imbaner/fallout2-ce-mobile) (F2 Touch), a touch port of [Fallout 2: Community Engine](https://github.com/fallout2-ce/fallout2-ce). This repository holds only the built files; the source code, issues and Android releases are in [imbaner/fallout2-ce-mobile](https://github.com/imbaner/fallout2-ce-mobile).

Unofficial fan port. Not affiliated with or endorsed by Microsoft, Bethesda Softworks, ZeniMax or Interplay. No game data is included: you need your own copy of Fallout 2 (GOG, Steam, Epic Games). The game files and saves stay in your browser.
